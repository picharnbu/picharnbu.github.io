Cross-Machine Storage Manager (CMSM)

CMSM is a personal storage manager for a Mac primary controller and a Windows lightweight agent. It archives selected, inactive local datasets to the owner's Google Drive and verifies the archived bytes before a local copy can become eligible for removal.

What the application does

  • Monitors available local storage against a 75 GB recovery target.
  • Schedules ordinary archive work for 23:00–05:00 Asia/Bangkok.
  • Uses the Mac as the sole transfer controller. The Windows agent serves explicitly configured local sources; it does not hold Google OAuth credentials or schedule cloud transfers.
  • Checks source and destination size, SHA-256, destination readability, transfer completeness and the archive manifest.
  • Supports checkpointed transfer, restart recovery and verified restoration.
  • Keeps market raw data permanently in its archive policy. CMSM provides no cloud-delete or cloud-prune operation.
  • Separates archive work from cleanup review. Cleanup reports candidates for human review and does not automatically delete them.

Google Drive access

CMSM requests the non-sensitive https://www.googleapis.com/auth/drive.file scope. This allows access to files created by the app and files the owner specifically authorizes for it. It does not authorize unrestricted access to the owner's entire Drive.

Backup contents, archive manifests and verification metadata are stored in the owner's Google Drive. The owner authorizes the Desktop OAuth client through Google's consent screen on the Mac. Credentials remain in a dedicated local configuration and are not entered into this website.

Current release

Version 0.1.0 is a candidate. Real Google Drive upload, readback, interrupted-transfer recovery and restoration have passed with a 52,000-byte synthetic fixture. That proof does not establish production readiness for every dataset. Production offload and local removal remain disabled pending producer/dependency checks, durable authorization, controller configuration reload and legacy scheduler cutover.
